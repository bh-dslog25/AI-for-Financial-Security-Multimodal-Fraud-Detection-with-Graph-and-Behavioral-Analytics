# AI for Financial Security: Multimodal Fraud Detection with Graph and Behavioral Analytics

This project explores fraud detection using financial transaction, customer, merchant, and card data with graph-based and behavioral analytics approaches.

## Project Structure

- `indian_fraud_dataset/` – Input datasets used for analysis
- `model/` – Jupyter notebook for exploratory data analysis and modeling work

## Getting Started

1. Clone this repository.
2. Open the notebook in `model/eda.ipynb`.
3. Install the required Python packages if needed.

## Notes

This repository is intended for experimentation and analysis related to fraud detection in financial datasets.
